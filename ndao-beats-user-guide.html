nDAO BEATS v1.0 — User Guide

The nDAO BEATS Parametric Curve Synthesizer is a browser-based creative tool that combines 3D parametric curve visualization with real-time audio synthesis and XPR Network blockchain integration. Design visual curves, map their mathematical properties to audio frequencies and filters, and permanently record your compositions on-chain using $BEATS tokens.

Key Features

  • Interactive 3D parametric and Fourier curve visualization with hue-mapped rendering
  • Multi-oscillator audio synthesizer with waveform selection, filter, and LFO modulation
  • Curve-to-audio mapping: X→frequency Y→filter Z→detune W→volume
  • Live XPR Network blockchain integration via WebAuth wallet
  • Mint compositions on-chain with full synth data in the transaction memo
  • $BEATS token (precision 8) via tokencreate contract on nftitledao
  • Export curves as PNG, JSON, or shareable links
  • Favourites system with local persistence

02Getting Started

Open ndao-beats-synthesizer.html in any modern browser (Chrome, Firefox, Edge, Safari). No installation or build step required — everything runs client-side.

Interface Overview

  • Header Bar — Mode tabs (Parametric, Fourier, Audio Synth), playback controls, Favourites, Wallet
  • Canvas Area — 3D curve rendering with drag-to-rotate and scroll-to-zoom
  • Left Panel Cards — X, Y, Z, W parameter cards showing ranges — click to open editor
  • Side Panel — Opens on right for Editor, Presets, Favourites, Audio Synth, and Chain panels
  • Equation Display — Top-left overlay showing current parametric equations
  • Audio Visualizer — Bottom frequency bar showing real-time audio spectrum

First Steps

  1. The app launches with the Butterfly preset in Parametric mode
  2. Drag the canvas to rotate the 3D curve; scroll to zoom
  3. Press A to open the Audio Synth panel, then click ▶ PLAY AUDIO
  4. Press W or click ⚡ CONNECT WALLET to link your WebAuth wallet
  5. Use ← → arrow keys to cycle through presets

03Parametric Curve Modes

Parametric Mode

Renders 3D curves defined by four parametric equations:

x(θ)Controls horizontal position
y(θ)Controls vertical position
z(θ)Controls depth (3D rotation affects visibility)
w(θ)Maps to hue color — the curve is rainbow-colored based on this value

8 built-in presets: Butterfly, Lissajous, Rose, Trefoil, Spirograph, Figure-8, Hypocycloid, Star.

Open the Equation Editor (press E) to modify equations live. The app auto-detects value ranges.

Fourier Mode

Displays 2D Fourier series decompositions as waveforms. Individual harmonics are shown faintly behind the composed signal. 4 presets: Square Wave, Sawtooth, Triangle Wave, Pulse.

Audio Synth Mode

Identical to Parametric mode but opens the Audio Synthesizer panel automatically. The curve's mathematical values drive the audio engine in real-time.

04Audio Synthesizer Engine

The synthesizer uses the Web Audio API to generate real-time sound from multiple oscillators, processed through a filter with LFO modulation.

Oscillators

Add up to 8 oscillators. Each has:

Waveformsine, triangle, sawtooth, or square
Frequency20–20,000 Hz (defaults: 220, 330, 440 Hz)
Detune±100 cents fine-tuning
Gain0–100% individual volume

Filter

A biquad filter processes the combined oscillator output:

Typelowpass, highpass, bandpass, or notch
Cutoff50–15,000 Hz
Resonance (Q)0.1–20.0

LFO (Low Frequency Oscillator)

Modulates the filter cutoff frequency for movement and texture:

Rate0.01–20 Hz
Depth0–500 (modulation intensity in Hz)

Curve → Audio Mapping

When audio is playing, the animated curve position modulates the audio in real-time:

X axisModulates oscillator frequencies (adds Hz offset)
Y axisModulates filter cutoff frequency
Z axisModulates oscillator detune (cents)
W axisModulates volume envelope (amplitude)
How it works
As the curve animates, each point's X/Y/Z/W coordinates are sampled and applied to the audio parameters. This creates a continuously evolving soundscape driven entirely by the curve's shape.

Connecting Your Wallet

  1. Click ⚡ CONNECT WALLET in the header (or press W)
  2. The WebAuth wallet selector modal appears
  3. Authenticate with your WebAuth wallet (biometric or password)
  4. Once connected, your account name and BEATS balance display in the header
  5. Sessions persist — returning to the page auto-restores your session
WebAuth SDK
The app loads @proton/web-sdk v4.2.20 from cdnjs (Cloudflare) with automatic fallback to unpkg and jsdelivr. If the SDK fails to load, the Connect button is disabled with a clear error.

Balance & Endpoints

The app queries your $BEATS balance with automatic endpoint fallback across 5 XPR Network API nodes. Balance auto-refreshes every 30 seconds while connected.

06Minting Compositions On-Chain

Minting permanently records your current curve and synthesizer configuration on the XPR Network blockchain.

How to Mint

  1. Connect your wallet (see Section 5)
  2. Configure your curve and audio settings
  3. Open the Chain panel (press W or click your account name)
  4. Review the CURRENT SYNTH STATE — shows all oscillators, filter, LFO, and curve data
  5. Review the ON-CHAIN MEMO PREVIEW — the exact string written to the blockchain
  6. Click ⛓ MINT ON-CHAIN (1 BEATS) — WebAuth prompts for approval
  7. Approve the transaction in your WebAuth wallet
  8. The confirmed TX appears in the Transaction Log with a link to explorer.xprnetwork.org

What Gets Stored

Each mint sends 1.00000000 BEATS to the nftitledao account. The transaction memo contains a compact encoding of your full synth state — oscillator waveforms, frequencies, detune values, gains, filter type/cutoff/Q, LFO rate/depth, master volume, curve name, mode, and timestamp.

Important
All transactions are LIVE on XPR Network mainnet. When you mint, real BEATS tokens are transferred. This is not a testnet or demo.

07On-Chain Memo Format

The transaction memo encodes your complete synthesizer state in a compact semicolon-delimited format (max 256 characters for XPR Network).

Example Memo

nDAO_BEATS_v1;curve:Butterfly;mode:parametric;osc:[sin:220Hz:d0:g0.8|tri:330Hz:d5:g0.4|saw:440Hz:d-3:g0.2];flt:low@2000Hz/Q1.0;lfo:0.5Hz*20;vol:30%;t:1711000000000

Field Reference

FieldDescription
nDAO_BEATS_v1Protocol identifier and version
curve:{name}Active curve preset name or "custom"
mode:{mode}Active mode: parametric, fourier, or audio
osc:[...]Oscillator array — each entry: waveform:frequency:detune:gain
flt:{type}@{freq}/{Q}Filter type (3 chars), cutoff Hz, and resonance Q
lfo:{rate}*{depth}LFO rate in Hz and modulation depth
vol:{percent}Master volume as percentage
t:{timestamp}Unix timestamp in milliseconds

Oscillator Entry Format

{wave}:{freq}Hz:d{detune}:g{gain}

Example: sin:220Hz:d0:g0.8 means sine wave at 220 Hz, 0 cents detune, 80% gain. Multiple oscillators are pipe-delimited (|).

Tip Memo Format

nDAO_BEATS_tip;from:{account};curve:{name};amt:{amount};t:{timestamp}

09Frequently Asked Questions

Q: What is $BEATS?
BEATS is a token on XPR Network created via the tokencreate contract with 8 decimal precision. It is used within the nDAO BEATS ecosystem for minting compositions and tipping.

Q: Do I need $BEATS to use the app?
No. The curve visualizer and audio synthesizer work without a wallet. You only need BEATS tokens to mint compositions on-chain or send tips.

Q: What wallet do I need?
A WebAuth wallet on XPR Network. Download the WebAuth app from webauth.com and create an account.

Q: Are transactions real?
Yes. All transactions go through XPR Network mainnet. When you mint, 1.00000000 BEATS is transferred live on-chain to the nftitledao account.

Q: Where can I verify my transactions?
Every confirmed transaction includes a link to explorer.xprnetwork.org where you can view the full transaction details including the memo data.

Q: What happens if the SDK fails to load?
The app tries 4 CDN sources (cdnjs Cloudflare, unpkg, jsdelivr, cdnjs unminified). If all fail, the wallet button shows ⚠ SDK FAILED. Refresh the page or check your internet connection.

Q: Can I edit equations?
Yes. Open the Equation Editor (press E) and modify any equation field. Use standard math functions: sin, cos, tan, abs, sqrt. The app auto-detects value ranges.
